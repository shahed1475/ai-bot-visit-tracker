Your sites

Enter the hostname only, for example example.com. Each site starts with its own private key. You can make more keys below.

API keys

A sending key lets a server or the edge sensor report bot visits for one site. A read key lets a script read your stats from /api/v1, and nothing else. Make a separate key for each place you use one, so you can revoke it on its own.
